# ADR-002: Drizzle ORM für Datenpersistenz

**Status:** Accepted  
**Datum:** 2025

## Kontext
Bewerbungsdaten, Unternehmensprofile und Bot-Status müssen persistiert werden.

## Entscheidung
Drizzle ORM mit TypeScript für typsichere Datenbankoperationen.

## Konsequenzen
**Positiv:**
- TypeScript-native, Schema ist Code
- Schnell und leichtgewichtig

**Negativ:**
- Jüngeres Ökosystem
